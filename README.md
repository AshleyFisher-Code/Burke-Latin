# Latin Practice

Phone-first vocab and grammar drills (cumulative by stage), with spaced review, streaks, a test-readiness light, and a parent view.

- `js/data.js` — word bank. Add a new stage's words here.
- `js/gen.js` — card builders and grammar skills.
- `js/srs.js` — scheduling, streaks, ranks, readiness.
- `tests/test.mjs` — exhaustive answer-key check: `node tests/test.mjs` must pass before every publish.
